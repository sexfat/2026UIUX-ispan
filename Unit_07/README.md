# 單元 7：介面視覺基礎：版面、排版、色彩與一致性

## 單元目標

- 理解視覺層級的概念，能夠運用大小、粗細、色彩區分資訊主次。
- 掌握版面設計的基礎原則，包含網格系統、留白與對齊。
- 了解色彩在介面設計中的角色，學會搭配主色、輔助色與中性色。
- 建立介面一致性的意識，理解為何設計規範對產品體驗至關重要。

## 課程介紹

本單元聚焦於介面視覺設計的基礎知識，幫助學員從「能做出介面」進階到「做出好看且清晰的介面」。課程將介紹視覺設計中最核心的四個面向：版面配置（如何安排資訊的位置與比例）、排版（字體選擇、字級與行距）、色彩運用（色彩心理與配色邏輯）以及一致性（如何讓整個產品看起來像一個整體）。

課程將透過好壞案例的比較分析，讓學員直觀感受視覺決策對使用者閱讀體驗的影響，並在 Figma 中進行對應的練習操作。

課程結束後，學員將能有意識地做出視覺決策，並能說明自己設計選擇背後的理由。
