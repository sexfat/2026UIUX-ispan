## 單元目標

- 能延伸並修正 Unit 06 的 Wireframe，使主要任務流程更完整。
- 能檢查 Wireframe 是否符合研究目標、資訊架構與使用者情境。
- 能透過同儕檢核找出流程斷點、資訊缺口與操作風險。
- 建立進入視覺風格與高保真設計前的版面品質標準。

## 課程介紹

這個單元會延續上一堂的 Flowchart、UI Flow 與 Wireframe，把初版骨架往可討論、可迭代的方向推進。重點不在增加頁面數量，而是確認每個頁面是否支援使用者完成任務。

舊課程中的檢核點精神會轉移到這裡：學會說明自己的設計決策，也學會從他人的提問中發現盲點。當 Wireframe 被問到「這裡為什麼要有這個欄位」、「使用者如果回上一頁會發生什麼」時，設計才開始變得可被驗證。

完成本單元後，Wireframe 應該能承接前面的研究成果，並為下一階段風格發想與 Mockup 細節打好基礎。此時仍不急著做精美視覺，而是先讓結構與流程站得住腳。

## 課程內容

- Wireframe 延伸：補齊主要頁、次要頁、關鍵表單與狀態節點。
- 流程檢核：入口、返回、錯誤、空狀態、任務完成與中斷情境。
- 資訊檢核：欄位必要性、資訊排序、行動按鈕與回饋訊息。
- 設計說明：用 Persona、旅程痛點與 IA 支撐版面決策。
- 同儕回饋：從提問、標註與修正紀錄中整理下一版 Wireframe。
