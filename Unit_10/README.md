# 單元 10：主要頁面 UI 設計實作（含 AI 輔助）

## 單元目標

- 能夠將 Wireframe 或草稿升級為具有完整視覺設計的高保真 UI 頁面。
- 整合前面所學的元件、樣式、Auto Layout 與視覺原則，完成核心頁面設計。
- 學會使用 AI 工具輔助文案生成、假資料填充與設計靈感發想。
- 培養在有限時間內完成設計稿的實作節奏與判斷力。

## 課程介紹

本單元是課程的核心實作階段，學員將正式進入個人專題的主要頁面 UI 設計。課程將示範如何從 Wireframe 出發，逐步加入視覺風格、色彩、字體與圖像，將骨架轉化為接近真實產品的高保真設計稿。

AI 工具將在本單元扮演重要的輔助角色——學員將學習如何用 AI 快速生成介面文案、產品描述、假用戶名稱等內容，填充設計稿並讓頁面更接近真實情境。老師也將示範如何善用 Figma 的社群資源（如 UI Kit）加速設計流程。

課程結束後，學員將完成至少 1–2 個核心頁面的高保真 UI 設計，並能說明設計中的視覺與互動決策。
