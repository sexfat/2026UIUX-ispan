## 功能說明

一堂 180 分鐘的課，把「只畫順利的路」的 Wireframe 補成能被檢核的一份完整流程：

1. **三種必畫的狀態**——把 Unit 06 的六種例外路徑對應成空狀態、錯誤狀態、載入狀態三類畫面。
2. **各自的設計準則**——空狀態三準則與「還沒有／找不到」的文案差別；錯誤訊息五要件與表單錯誤回報十條；回應時間三門檻與進度指示三型別；指示器／驗證／通知的分工。
3. **合成與標註**——把散裝畫面接成一張沒有斷點的 Wireflow，並寫出時間、條件、規則、動態行為這四類畫不出來、只能用文字寫的標註。
4. **同儕檢核**——設計檢核的三個前提與四種角色、把個人偏好改寫成對著目標的提問，以及檢核結束後的四步修正紀錄（原話／決定／理由／下一步）。

課堂 85 分鐘全在改同一條流程。學生可用自己專題的流程，或用三張指定題目卡其中一題（會員註冊與登入／結帳付款出錯／中途離開與返回），題目之間沒有分數差別。
