## 功能說明

三份互相串接的 HTML 教材，加上一個 Figma 課堂練習板：

**簡報 `slides.html`（26 張）**
封面 → 議程 → 研究到結構的位置 → IA 定義 → IA/導覽/Sitemap 差異 → 三個關鍵模型 → 可尋性 vs 可發現性 → 資訊氣味 → 扁平 vs 深層 → 三次點擊迷思 → 常見 IA 錯誤 → 洞察到功能清單 → 功能清單範例 → Functional Map → 卡片分類法 → 開放式 vs 封閉式 → 四步驟 → 常見偏誤 → 結果分析 → 樹狀測試 → 內容模型 → 命名 4 個 S → IA 圖製作 → 課堂練習 → 回家作業 → 延伸資源。

**講義 `article.html`（14 節）**
在簡報基礎上展開，另含「導覽設計」專節與四段可複製的 AI 協作提示詞，以及 13 條 NN/g 參考資料。

**練習 `exercises.html`**
- 課堂練習：電商後台卡片分類法，四階段 80 分鐘（準備 15 / 開放式 25 / 封閉式 18 / 分析與 IA 草圖 22），另計 15 分鐘成果分享。
- 回家作業：網站 Sitemap 分析，依指定影片三模型框架的五個步驟，附 100 分配比評分表。

**Figma 練習板**
FigJam 六個工作區：使用說明、卡片區（13 張顏色統一且隨機打散的便利貼）、開放式分類工作區、封閉式分類工作區、分析區、IA 草圖區。
