# 單元 2：設計思考與 AI 在設計與開發流程中的協作

## 單元目標

- 理解設計思考（Design Thinking）的五個階段：同理、定義、發想、原型、測試。
- 能夠將設計思考框架應用在實際問題的分析與解決上。
- 了解 AI 工具如何在設計與開發的不同階段提供協助。
- 掌握人機協作的思維，學會善用 AI 加速設計流程。

## 課程介紹

本單元深入介紹設計思考的核心框架，並探討 AI 如何成為設計師與開發者的協作夥伴。課程將透過實際案例說明設計思考各階段的操作方式，包含使用者訪談、需求定義、腦力激盪與快速原型等技巧。

在 AI 協作的部分，課程將示範如何使用 AI 工具輔助需求整理、使用者旅程規劃、User Flow 草稿與 Wireframe 的快速產出，讓設計師能將更多精力投入在策略與創意決策上。

課程結束後，學員將能運用設計思考框架拆解設計問題，並實際嘗試以 AI 工具協助 User Flow 與 Wireframe 的製作。
