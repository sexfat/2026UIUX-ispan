## 課程介紹

這個單元會把第一堂的產業觀念推進到「可以做什麼題目」。主題發想不是隨機找一個 App 來做，而是從使用情境、痛點、商業限制與可執行範圍中，找到值得被設計處理的問題。

設計思考會作為本單元的主要框架。第一顆鑽石用來發現與定義問題，第二顆鑽石用來發展與收斂方案；過程中會練習把抱怨改寫成 HMW 問句，再透過 Brainstorming 與 Crazy 8s 把抽象問題變成可視化構想。

AI 可以成為發想時的第 N 位組員：當點子過度相似時，它能提出極端方案；當問題太散時，它能協助歸納衝突。不過 AI 的回覆只是一批假設，最後仍要回到團隊能否說清楚「為什麼要做這個題目」。

## 課程內容

- 設計思考五階段：同理、定義、發想、原型、測試。
- 雙鑽石模型：Discover / Define / Develop / Deliver。
- HMW 問句撰寫：把抱怨轉成可設計的機會。
- Brainstorming 與 Crazy 8s：追求數量、打破第一直覺、快速視覺化。
- AI 協作提示詞：虛擬訪談、痛點歸納、極端點子、功能地圖邏輯審查。
- 期中專題主題發想的題目篩選與討論標準。
