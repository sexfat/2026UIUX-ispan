# 單元 12：作品展：專題發表與講評
> 對應資展時段：2026/08/19（三）09:00–16:30
> 本單元為學員作品展與專題發表，不安排課程簡報。

## 單元目標

- 完整展示專題的研究脈絡、設計流程與最終成果。
- 能在發表中清楚說明問題、方法、設計取捨、成果與反思。
- 能回應講師與同學的提問，說明個人角色、方法選擇與作品亮點。
- 依現場講評整理後續優化方向，作為作品集與期末專題的基礎。

## 活動介紹

最後一個單元是學員作品展與專題發表，不是一般授課時段，也不使用課程簡報。學員會把前面單元累積的研究、流程、Wireframe、風格探索與 Mockup 整理成完整提案，向現場觀眾說明「為什麼做、怎麼研究、如何取捨，以及最後完成了什麼」。

發表內容可依專題需要呈現問題背景、競品分析、Persona、旅程地圖、資訊架構、Flowchart、Wireframe、風格板、Mockup 與 APP 介面。重點不是堆疊成果圖，而是讓觀眾理解每個關鍵設計決策的依據。

每組發表後安排提問與講評，聚焦專題論述、使用者價值、設計完整度與後續改善方向。學員應記錄回饋，作為作品集整理及後續專題優化的依據。

## 作品展流程

- 作品展示與專題發表。
- 專題背景、使用者問題與研究洞察說明。
- 設計流程、關鍵取捨與最終介面成果展示。
- 現場提問、講師講評與同儕回饋。
- 回饋紀錄與後續優化方向整理。
