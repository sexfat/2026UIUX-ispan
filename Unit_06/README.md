## 課程介紹

這個單元開始從研究文件進入介面骨架。Flowchart 用來描述邏輯與分支，UI Flow 用來描述使用者在畫面之間如何移動，Wireframe 則把流程轉成初步版面，先處理資訊順序與操作關係。

Wireframe 階段不追求視覺精緻，而是確認「這個頁面應該有哪些資訊、哪些動作、使用者下一步在哪」。如果在這個階段就急著做色彩與圖片，容易掩蓋流程問題；因此本單元會刻意使用低保真方式，讓討論集中在結構。

舊課程中的 Auto Layout 會被放進 Wireframe 製作脈絡。透過水平、垂直容器、Padding、Spacing 與 Resizing，可以更快建立可調整的卡片、列表、按鈕群與表單骨架，讓後續版面變動不必重畫。

## 課程內容

- Flowchart：任務步驟、判斷點、錯誤與返回路徑。
- UI Flow：頁面節點、跳轉關係、主要任務線與例外線。
- Wireframe：內容區塊、資訊層級、操作入口與版面順序。
- Figma Auto Layout：水平 / 垂直容器、Padding、Spacing、Resizing。
- Constraints：理解不同 Frame 尺寸下的對齊與縮放行為。
- 從 IA 到 Wireframe：把產品結構轉成 3–5 個關鍵畫面。
