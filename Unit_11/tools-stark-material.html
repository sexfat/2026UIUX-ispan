Figma Plugin Guide

Stark 與 Material Theme Builder
操作指南

這兩個外掛都列在講義的「參考資料」裡，這頁教怎麼在作業 9 的 Figma 檔案裡實際用起來：Stark 檢查對比度是否過關，Material Theme Builder 產生 Android 專題要用的 Material 配色。

Overview · 01

一個檢查對比度，一個產生配色

兩個工具都是免費的 Figma 外掛，處理的是不同階段的問題：

Stark

在畫面畫好之後檢查：文字跟背景的對比度夠不夠、色盲模擬下還看不看得清楚。對應講義 §9 的 WCAG 2.2 門檻（一般文字 4.5:1、大字或圖示 3:1）。

Material Theme Builder

在畫面開始前先產生：輸入一個品牌色，自動算出 Material Design 3 的完整配色角色（Primary、Secondary、Container…）。專題選 Android 平台時才需要。

兩個都不是必修工具。手動調色、手動算對比度一樣可以交作業；這兩個外掛的價值是把「算對比度」「配出一整組協調的顏色」這兩件耗時的事自動化，讓時間留給版面判斷。

Stark Setup · 02

Stark：安裝與啟用

  1. 在 Figma 裡打開你的作業 9 檔案，上方選單找 Resources（或按 Shift + I）。
  2. 切到 Plugins 分頁，搜尋 Stark，選官方這一個（作者是 Stark Accessibility Suite）。
  3. 點 Run 第一次執行後，Stark 會出現在右側面板；之後可以直接從 Resources → Plugins → Stark 開啟，不用重新搜尋。
  4. 免費版就能做對比度檢查與色盲模擬，這是本單元用得到的部分；付費功能（如自動修復建議）不是必要項目。

外掛介面會隨版本更新。以下步驟講的是操作邏輯，實際選單文字若跟畫面對不上，以 Stark 外掛內建的引導為準。

Stark Usage · 03

Stark：檢查對比度

  1. 選取要檢查的物件：通常是一段文字圖層，加上它下面的背景圖層（兩個一起選）。
  2. 開啟 Contrast Checker：在 Stark 面板裡選對比度檢查功能，它會讀出選取物件的文字色與背景色，算出對比度數值。
  3. 對照講義 §9 的門檻：一般文字要 ≥ 4.5:1；18pt 以上的大字或粗體 14pt 以上、以及圖示與控制邊界只要 ≥ 3:1。Stark 會直接標示這組顏色是否通過 AA／AAA。
  4. 沒通過就調整：Stark 通常可以微調文字色或背景色，即時看對比度數值變化，調到通過門檻為止。
  5. 色盲模擬：Stark 也能模擬幾種常見色盲類型下的畫面，用來檢查「狀態只靠顏色分辨」這類問題（對應講義 §9「狀態不只依賴顏色」）。

放進檢核表：用 Stark 跑過的畫面，可以直接對照 APP 介面檢核表 G 組「無障礙」的對比度項目打勾，勾選結果可以直接複製進作業說明。

Material Theme Builder Setup · 04

Material Theme Builder：安裝與啟用

  1. 同樣從 Resources（Shift + I）→ Plugins，搜尋 Material Theme Builder，選 Google 官方發布的版本。
  2. 點 Run 執行，外掛會在右側面板打開一個配色產生介面。
  3. 這個外掛只在 Android／Material Design 專題時需要；iOS 專題沿用 HIG 的系統色即可，不必安裝。

Material Theme Builder Usage · 05

Material Theme Builder：產生配色

  1. 選一個品牌色（Source Color）：通常是 Logo 主色或最能代表產品的一個顏色，貼上色碼。
  2. 產生色板：外掛會依這個色自動算出 Material Design 3 的完整角色，包含 Primary／Secondary／Tertiary，以及每個角色對應的 Container、On-Primary 等文字色。
  3. 檢查明暗兩套主題：Material 3 預設同時給 Light／Dark 兩組數值，確認兩套在你的畫面上都好讀。
  4. 套用到 Figma 變數或色票：外掛通常能把整組顏色匯出成 Figma Variables 或 Color Styles，之後畫面直接套用這些變數，換色只要改一個 Source Color。

為什麼不要手動配色：Material 3 的角色系統（Primary/Secondary/Container…）彼此有固定的對比關係，手動配容易配出視覺上好看、但 Primary 文字疊在 Primary 背景上對比不足的組合。用外掛產生可以保證這組關係本來就成立，對應講義 §9 的對比門檻。
