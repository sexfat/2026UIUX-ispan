# 單元 11：次頁、狀態頁與細節優化（案例展示）

## 單元目標

- 能夠設計主流程以外的次要頁面，如細節頁、表單頁、付款頁等。
- 理解空狀態、錯誤狀態、載入狀態等介面狀態的設計重要性，並能實作。
- 學會從整體流程的角度檢視設計稿，補足使用體驗中的缺口。
- 透過案例展示，從優秀的真實產品設計中汲取靈感與細節處理技巧。

## 課程介紹

本單元是課程的收尾實作階段，聚焦於「完整體驗」的建構。許多初學者容易只設計主要頁面，而忽略了使用者在實際操作中會遇到的各種狀況——找不到資料時的空狀態、操作失敗時的錯誤提示、等待回應時的載入畫面，這些細節往往是決定產品質感的關鍵。

課程將帶領學員補完個人專題中的次要頁面，並針對常見的介面狀態進行設計練習。同時，課堂也將透過精選的真實產品案例展示，解析優秀設計在細節處理上的思維與技巧，作為學員精修設計稿的參考依據。

課程結束後，學員將完成一套包含主要頁面、次頁與多種介面狀態的完整設計稿，為後續的 Prototype 製作與作品展示做好準備。
