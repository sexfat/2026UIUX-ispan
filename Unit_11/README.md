## 課程介紹

這個單元聚焦 APP UI 設計規範。iOS 與 Android 在導覽、元件、手勢、狀態列、安全區域與互動慣例上有不同期待；設計 APP 介面時，需要尊重平台習慣，而不是把 Web 版縮小後直接放進手機。

內容從常見 APP 介面案例出發，建立行動端資訊密度、觸控目標、單手操作與平台慣例的基本意識，並將既有專題內容轉換成適合手機情境的頁面。

## 課程內容

- iOS / Android 規範概念：導覽模式、系統列、安全區域、觸控目標與手勢。
- APP Wireframe / Mockup：行動端資訊密度、單手操作與平台慣例。
- 常見 APP 元件：導覽列、Tab、表單、列表、卡片、Dialog 與操作回饋。
- APP 介面檢核：一致性、可用性、觸控範圍與平台規範意識。
