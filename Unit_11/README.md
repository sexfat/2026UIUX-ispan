- 能完成符合 iOS / Android 規範意識的 APP 介面頁面。

## 課程介紹

這個單元會把 Mockup 從「主要頁面」推進到「完整體驗」。許多設計稿只畫首頁或流程成功的畫面，但真實使用會遇到空狀態、載入、錯誤、表單驗證、權限要求與操作中斷；這些細節會直接影響產品是否可信。

舊課程中的狀態頁與細節優化會在上午延伸：空狀態要提供下一步，錯誤狀態要指出問題與修復方式，載入狀態要讓使用者知道系統正在處理。這些設計會回到十大易用性原則中的系統狀態、錯誤復原與說明支援。

下午會進入 APP 設計規範。iOS 與 Android 在導覽、元件、手勢、狀態列、安全區域與互動慣例上有不同期待；設計 APP 介面時，需要尊重平台習慣，而不是把 Web 版縮小後直接放進手機。

## 課程內容

- Mockup 延伸：次頁、細節頁、表單頁、確認頁與任務完成頁。
- 介面狀態：Loading、Empty、Error、Success、Disabled、Pressed、Focus。
- 錯誤與回饋：表單驗證、Snackbar / Toast、Dialog、Undo 與救援路徑。
- iOS / Android 規範概念：導覽模式、系統列、安全區域、觸控目標與手勢。
- APP Wireframe / Mockup：行動端資訊密度、單手操作與平台慣例。
- 專題細節微調：一致性、可用性、視覺精度與展示完整度。
