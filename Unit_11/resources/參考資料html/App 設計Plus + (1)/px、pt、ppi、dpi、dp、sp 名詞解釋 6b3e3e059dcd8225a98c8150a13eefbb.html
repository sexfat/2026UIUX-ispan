px、pt、ppi、dpi、dp、sp 名詞解釋

px、pt、ppi、dpi、dp、sp

1. Figma 中的單位與 Android/iOS 設計單位對應

  • Figma 的 px（像素）：
    • 對應 Android 的 dp 和 iOS 的 pt，因為在標準設置下：
      • 1 dp = 1 px（在設計時假設屏幕密度為 160 dpi）。
      • 1 pt = 1 px（在設計 iOS 介面時假設相同比例）。

單位對應簡表

單位使用場景在 Figma 中對應方式
px（像素）Figma 的默認單位Figma 默認使用 px 單位，無需轉換。
pt（點）iOS 的邏輯單位在 Figma 中設計時等同於 px。
dp（密度無關像素）Android 的邏輯單位在 Figma 中設計時等同於 px。
sp（縮放無關像素）Android 的文字大小單位在 Figma 中設計時等同於 px，並手動考慮用戶字體縮放影響。
dpi（每英寸像素）屏幕密度不直接涉及 Figma，作為輸出參考。

2. 設定畫布與設備尺寸

在設計前，需要正確設定畫布，模擬真實設備的邏輯分辨率：

(1) Android 設備

  • Android 使用 dp 作為設計單位，將設備的邏輯分辨率作為畫布尺寸。
  • 範例畫布尺寸：
    • 小型手機（例如 Pixel 4a）：360 x 640 px。
    • 大型手機（例如 Pixel 7 Pro）：412 x 892 px。
    • 平板電腦：800 x 1280 px。
  • 在 Figma 中，直接輸入這些邏輯尺寸即可開始設計。

(2) iOS 設備

  • iOS 使用 pt 作為設計單位，畫布尺寸通常為設備的邏輯分辨率。
  • 範例畫布尺寸：
    • iPhone SE：375 x 667 px。
    • iPhone 14 Pro：430 x 932 px。
    • iPad Air：820 x 1180 px。
  • 直接設定這些尺寸作為畫布大小。

3. Figma 設計中的文字單位（SP）

  • Android 的文字單位為 sp，需要考慮系統字體縮放（如 Accessibility 設置的 1.2x 或 1.5x）。
  • 在 Figma 中：
    • 設計文字時，默認以 px 設置文字大小。
    • 若需考慮縮放影響，可手動計算文字大小。
      • 例如：設計 16sp 的文字，若字體縮放為 1.2x，應設定文字大小為 16×1.2=19.2px。

        16×1.2=19.2px16 \times 1.2 = 19.2 px

4. 圖片與圖標資源輸出

(1) Android 資源輸出

  • Android 需要多分辨率資源，根據 dpi 設置導出不同的尺寸：
    • mdpi（1x）：直接使用設計尺寸。
    • hdpi（1.5x）：設計尺寸的 1.5 倍。
    • xhdpi（2x）：設計尺寸的 2 倍。
    • xxhdpi（3x）：設計尺寸的 3 倍。
    • xxxhdpi（4x）：設計尺寸的 4 倍。
  • 範例：
    • 圖標大小為 24dp，輸出尺寸為：
      • mdpi：24px
      • hdpi：36px
      • xhdpi：48px
      • xxhdpi：72px
      • xxxhdpi：96px

(2) iOS 資源輸出

  • iOS 需要多分辨率資源，對應 @1x、@2x、@3x：
    • @1x：設計尺寸。
    • @2x：設計尺寸的 2 倍。
    • @3x：設計尺寸的 3 倍。
  • 範例：
    • 圖標大小為 24pt，輸出尺寸為：
      • @1x：24px
      • @2x：48px
      • @3x：72px

5. 轉換公式與工具

公式

  1. Android dp 和 px 的轉換：px=dp×(dpi/160)

    px=dp×(dpi/160)px = dp \times (dpi / 160)

    • 例如：24dp，設備密度為 320 dpi：
      px=24×(320/160)=48px

      px=24×(320/160)=48pxpx = 24 \times (320 / 160) = 48px

  1. iOS pt 和 px 的轉換：
    • iOS 的 pt 和 px 在設計中直接等同。

工具

  • 使用 Figma 插件：
    • Pixels to DP/Sp Converter：協助轉換 dp 和 sp。
    • Material Design Kit：包含 Android 設計資源和規範。

6. 總結

  • 畫布大小：使用設備的邏輯分辨率（以 dp 或 pt 為單位）。
  • 文字設置：直接使用 px 作為大小，但手動考慮 Android 的文字縮放（sp）。
  • 資源輸出：導出多分辨率資源，對應 Android 的 dpi 和 iOS 的 @x 倍數。
