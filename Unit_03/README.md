# 單元 3：Figma 基礎操作與討論

## 單元目標

- 熟悉 Figma 介面與基本操作，包含畫布、圖層、工具列與快捷鍵。
- 能夠建立 Frame、使用基本形狀工具，並進行對齊與間距設定。
- 理解圖層命名與結構整理的重要性。
- 能夠完成一個簡單頁面的版面配置。

## 課程介紹

本單元為 Figma 的入門實作課，帶領學員從零開始認識這套業界主流的設計工具。課程將逐步介紹 Figma 的核心功能，包含 Frame 的概念、物件的基本操作（移動、縮放、對齊）、圖層面板的管理，以及文字與色彩的設定方式。

課程採用邊講邊做的方式進行，學員將跟著老師一步步完成一個簡單的介面版面，建立對 Figma 工作流程的基本認識。課堂也會保留討論時間，針對學員在操作上遇到的問題進行解答。

課程結束後，學員將能獨立在 Figma 中建立基本版面結構，並養成良好的圖層命名習慣。
