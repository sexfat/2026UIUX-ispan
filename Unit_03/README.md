## 課程介紹

這個單元正式進入用戶研究。競品分析的目標不是抄畫面，而是看懂同類產品如何定義問題、安排功能、降低操作成本，並從比較中找出自己的設計機會。

Persona 會接在競品分析之後，用來錨定後續設計決策。好的 Persona 需要包含目標、心智模型、使用環境、痛點與行為線索；它不是「25 歲上班族」這種標籤，而是能回答「這位使用者在這個情境下最不能忍受什麼」。

Figma 與 FigJam 會作為研究整理工具使用。便利貼、分群、表格與 Persona 模板能讓研究資料變得可討論；AI 則可用來建立初始角色、模擬訪談與提煉功能需求，但所有輸出都要視為假設，而不是研究結論。

## 課程內容

- 競品分析：案例搜集、表格化比較、功能與流程觀察。
- Persona 的深層構成：Goals、Mental Model、Context、Pains、Gains。
- 避免「彈性使用者」陷阱：用具體角色作為決策基準。
- Persona 提示詞流程：設定 UX 研究員角色、深度定義角色、虛擬訪談、映射功能需求。
- FigJam / Figma 入門：便利貼整理、分群、表格、Persona 版面。
- 從 Persona 回推 Functional Map 的核心路徑、邊緣案例與資訊層級。
