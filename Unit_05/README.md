# 單元 5：作業探討 第一次檢核點（個人專題）

## 單元目標

- 回顧並整合前四個單元所學的設計概念與 Figma 操作技能。
- 能夠清楚說明個人專題的設計方向、目標使用者與主要功能。
- 透過同儕討論與老師回饋，發現設計稿中的問題並提出改善方向。
- 培養設計簡報與口頭說明的能力。

## 課程介紹

本單元為課程的第一個檢核點，以作業討論與個人專題發表為主軸。學員將展示截至目前的設計成果，包含設計思考的過程、User Flow、Wireframe 或初步的介面版面，並接受老師與同學的提問與建議。

課堂採用小組或全班討論的形式進行，每位學員有機會說明自己的設計決策，並從他人的回饋中獲得新的視角。老師也將在此階段針對常見問題進行統一說明，幫助學員在進入後半段課程前夯實基礎。

課程結束後，學員將能根據回饋調整專題方向，並帶著更清晰的設計目標進入後續實作階段。
