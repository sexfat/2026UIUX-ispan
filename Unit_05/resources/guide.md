## 1. 資訊架構與組織原則

如果你是資訊架構實務的新手，請從這裡開始！本節文章介紹了什麼是資訊架構，以及它與導覽有何不同（但又有所關聯）。要成為成功的資訊架構師，還需要瞭解人們如何尋找資訊，我們涵蓋了支援這些行為的常見組織結構。此外，本節還介紹了分類的最佳實踐，以及讀者針對全站導覽（Global Navigation）廣度與深度所提出的常見疑問。

## 2. 資訊架構的研究方法

資訊架構有一些獨特的研究方法，例如卡片分類法（Card Sorting）和樹狀測試（Tree Testing），這些方法與其他常見的 UX 研究方法略有不同。**卡片分類法**是用於資訊架構發想探討的形式，能讓我們了解使用者如何自然地將資源進行歸類；**樹狀測試**則允許我們測試擬定的資訊架構，看看使用者能否找到關鍵項目。本節資源將為如何規劃、執行與分析資訊架構研究提供指引。

此外，標準的使用者研究方法（如定性可用性測試）通常也能產生關於資訊架構的實用發現，因此我們也建議參考我們關於[定性可用性測試](https://www.google.com/search?q=https://www.nngroup.com/articles/qualitative-ux-research-study-guide/)與[定量研究](https://www.google.com/search?q=https://www.nngroup.com/articles/quantitative-ux-research-study-guide/)的學習指南。

### 卡片分類法（Card Sorting）

2. **[開放式 vs. 閉合式卡片分類](https://www.nngroup.com/videos/open-vs-closed-card-sorting/)**（影片）— 解釋兩種主要卡片分類類型及其適用場景。

4. **[卡片分類法：需要測試多少使用者](https://www.google.com/search?q=https://www.nngroup.com/articles/card-sorting-how-many-users/)**（文章）— 卡片分類研究的樣本量指南。

6. **[如何解讀卡片分類的樹狀圖以改善資訊架構](https://www.google.com/search?q=https://www.nngroup.com/videos/dendrograms-card-sorting/)**（影片）— 分析樹狀圖（即卡片分類結果視覺化）的指引。

## 頁面內容分析與總結

這篇由 [Nielsen Norman Group (NN/G)](https://www.nngroup.com/articles/ia-study-guide/) 撰寫的《資訊架構學習指南》，是一個針對 UX 設計師、產品經理及資訊架構師的系統化學習資源庫。全文分為三大核心領域：

### 1. 核心觀念與組織原則（Foundations）

* **IA $\neq$ 導覽：** 資訊架構是底層的資料結構與邏輯，而導覽只是將其呈現給使用者的介面。
* **導覽與搜尋並重：** 破解「有了搜尋框就不需要導覽」以及「點擊不應超過 3 次」的迷思；強大的導覽能建立明確的「資訊氣味（Information Scent）」，引導使用者探尋內容。
* **明確的命名與分類：** 避免如「了解更多」這類模糊的標籤，並透過多重層級（Polyhierarchy）與合理處置邊緣分類，提升內容的可尋性（Findability）。

### 2. 資訊架構研究方法（Research & Validation）

* **卡片分類法（Card Sorting）：** 常用於**發想階段**，藉由觀察使用者如何主動分組內容，來探索並建立符合使用者「心智模型」的架構。
* **樹狀測試（Tree Testing）：** 常用於**驗證階段**，去除了 UI 視覺干擾，僅以純文字樹狀結構測試使用者能否順利找到目標內容，用以衡量導覽架構的可行性。

### 3. UI 導覽設計與落地（UI Patterns）

* **方向感與尋路機制：** 運用麵包屑（Breadcrumbs）、區域導覽與明確的「你在此處」指示，幫助使用者掌握自己在網站中的位置。
* **不同情境下的模式選擇：**
* **桌機端：** 巨型選單（Mega Menus）與左側垂直導覽適合龐大複雜的架構；警惕過度使用隱藏式導覽（如桌機端的漢堡選單）。
* **行動端：** 需善用摺疊式選單（Accordion）與清晰的意象符號（Signifiers）來節省空間，同時兼顧層級可讀性。



---

> **結論**
> 好的資訊架構起於對使用者心智模型的理解（透過卡片分類與樹狀測試驗證），終於清晰易讀的介面呈現（透過強資訊氣味的標籤與適合情境的導覽模式）。這份指南提供了從觀念建立到研究實作、最終落實為 UI 設計的全套知識藍圖。
