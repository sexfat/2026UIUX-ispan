# 單元 1：業界觀念建立與職能定位
> 對應資展時段：2026/06/26（五）09:00–12:00
> 課堂簡報：`slides_unit01.html`

## 單元目標

- 建立 UI、UX 與產品設計在產業中的基本分工認知。
- 理解科技團隊中設計師、工程師、PM 與行銷角色的協作關係。
- 認識 UX 設計流程從需求、研究、發想到介面產出的主要階段。
- 了解 AI 工具在研究整理、發想、文案與介面產出中的輔助位置。

## 課程介紹

這個單元是整門課的起點，重點不是先學工具，而是先看懂 UI/UX 設計在產業裡解決什麼問題。學完後，會更清楚 UI 不只是把畫面做漂亮，UX 也不是憑感覺猜使用者喜好，而是把需求、情境、流程與介面決策串成可被討論的工作方法。

課程會從常見產品與介面案例切入，拆解設計師在專案中的職能任務：如何理解商業目標、辨識使用者需求、整理功能範圍，並把想法轉成後續能進入研究、Wireframe 與 Mockup 的材料。

AI 會被放在設計流程中的輔助位置：它可以協助整理資料、刺激發想、產生初稿與補足文案，但不能取代對使用者與產品情境的判斷。這一點會成為後續 Persona、功能地圖與作品集敘事的基礎。

## 課程內容

- UI 與 UX 的差異、關聯與常見誤解。
- 科技產品團隊中的職能分工與溝通介面。
- UX 流程總覽：研究、定義、發想、原型、測試與交付。
- AI 在需求釐清、研究摘要、發想、文案與介面產出中的協作方式。
- 從 Persona 與 Functional Map 看「使用者價值」如何轉成設計決策。
