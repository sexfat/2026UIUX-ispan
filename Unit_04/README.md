## 課程介紹

Persona 幫助我們定義「誰在使用」，用戶旅程地圖則進一步描述「他如何完成一件事」。這個單元會把使用者從產生需求、尋找資訊、採取行動到完成任務的過程攤開，找出每個階段的情緒起伏與阻力。

旅程地圖的重點不只是列流程，而是看出體驗中的峰值與落差。甜點代表可以被強化的正向時刻，痛點代表阻礙任務完成或造成焦慮的節點；兩者都會影響後續功能優先順序與介面設計目標。

完成旅程地圖後，設計目標會從抽象方向變成可執行句子，例如降低等待焦慮、縮短比較時間、讓新手更容易確認下一步。這些目標會成為資訊架構、Flowchart 與 Wireframe 的判斷依據。

## 課程內容

- 用戶旅程地圖結構：階段、行為、想法、情緒、接觸點與機會。
- 峰值體驗：使用者最有感的正向或負向時刻。
- 甜點與痛點：強化價值、降低阻力、找出介面改善優先順序。
- 從旅程問題到設計目標：將觀察轉成可檢核的設計方向。
- Figma 旅程地圖製作：欄位規劃、情緒曲線、標註與討論版本管理。
