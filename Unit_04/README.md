# 單元 4：Auto Layout、Constraints 與彈性版面

## 單元目標

- 理解 Auto Layout 的概念與運作邏輯，能夠建立水平與垂直排列的彈性容器。
- 掌握 Padding、Spacing、Resizing 等 Auto Layout 屬性的設定方式。
- 了解 Constraints 在不同螢幕尺寸下的版面響應行為。
- 能夠用 Auto Layout 重構元件，使其具備彈性縮放能力。

## 課程介紹

本單元聚焦於 Figma 最重要的進階功能之一——Auto Layout。透過 Auto Layout，設計師可以讓元件與版面自動響應內容變化，大幅提升設計稿的靈活性與維護效率。

課程將從基本概念出發，示範如何將靜態版面改寫成 Auto Layout 結構，並說明 Constraints 如何控制元件在不同尺寸 Frame 中的對齊與縮放行為。學員將透過實際操作練習，體驗 Auto Layout 在真實設計情境中的應用，例如按鈕自動撐寬、列表項目動態增減等。

課程結束後，學員將能用 Auto Layout 建立具有彈性的元件與版面，並理解響應式設計的基本思維。
