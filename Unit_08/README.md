## 課程介紹

這個單元從 Wireframe 進入視覺方向。風格不是單純挑喜歡的顏色，而是把產品定位、使用情境、目標族群與競品差異轉成可被執行的視覺語言。

舊課程中的視覺基礎會在這裡重新整合：網格、留白、對齊、字級、行距、主色、輔助色與中性色，都會成為風格板裡需要被說明的決策。好的風格板要能讓後續 Mockup 有一致方向，而不是每個頁面重新猜一次。

完形心理學與 Laws of UX 也會被帶入風格討論。接近性、相似性、共同區域、Hick's Law、Fitts' Law 等原則，可以幫助判斷畫面是否容易掃讀、操作目標是否清楚、視覺分組是否符合使用者直覺。

## 課程內容

- 市場風格分析：競品視覺語言、品牌語氣、常見版面模式。
- 風格故事化：從產品定位與使用情境描述視覺方向。
- 視覺基礎：網格、留白、對齊、排版、色彩與一致性。
- 完形心理學：接近性、相似性、連續性、封閉性、共同區域。
- Laws of UX：Hick's Law、Fitts' Law、Miller's Law、Jakob's Law。（https://lawsofux.com/）
- Style Tile / Moodboard：色彩、字體、元件氛圍、圖片方向與說明文字。
- UI 設計系統概念：Design Token、元件與規範三層結構，以及 Figma 的 Styles、Component 與 Variants 對應做法。
