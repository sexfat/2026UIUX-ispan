# 單元 8：元件、樣式與設計系統概念

## 單元目標

- 理解 Figma 元件（Component）的概念，能夠建立與管理可重複使用的元件。
- 學會使用 Figma Styles 定義色彩、文字樣式，建立設計規範的基礎。
- 了解設計系統（Design System）的組成與在團隊協作中的重要性。
- 能夠建立一套基礎元件庫，供後續頁面設計使用。

## 課程介紹

本單元介紹設計規模化的關鍵概念——元件與設計系統。當設計稿頁面越來越多，如何讓按鈕、卡片、導航列等重複出現的元素保持一致，並在需要修改時能一次更新所有位置，是每位設計師必須面對的課題。

課程將帶領學員在 Figma 中實作元件的建立、命名與管理，並說明 Master Component 與 Instance 的關係。同時，課程也將介紹如何用 Color Styles 與 Text Styles 建立設計語言的基礎，為後續的高保真設計稿奠定規範。

課程結束後，學員將能建立一套包含基礎按鈕、輸入框、卡片與導航的元件庫，並能說明設計系統對產品一致性的貢獻。
